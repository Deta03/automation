# Currency Exchange Rate

Python-скрипт для получения курса одной валюты относительно другой на указанную дату через Web API.

## Установка

Требуется Python 3 и библиотека requests:

pip3 install requests

## Запуск

python3 currency_exchange_rate.py FROM TO DATE API_KEY

Пример:

python3 currency_exchange_rate.py USD EUR 2025-09-15 EXAMPLE_API_KEY

## Работа программы

Скрипт получает валюты, дату и API-ключ из командной строки. Затем отправляет запрос к Web API, получает данные о курсе в формате JSON и сохраняет результат в папку `data`.

Имя файла формируется из валют и даты:

USD_EUR_2025-09-15.json

Если возникает ошибка, она выводится в консоль и записывается в `error.log`.

## Тестирование

Программа была протестирована с разными валютами и датами, а также с неправильными параметрами и API-ключом.

Диапазон доступных дат: 2025-01-01 — 2025-09-15.
